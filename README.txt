ڤايات طحينة — دليل الاستخدام والنشر (GitHub Pages)
====================================================

الملفات:
  index.html              = الموقع اللي بيشوفه العميل (للقراءة فقط)
  admin.html              = صفحة الأدمن (محمية بكلمة مرور)
  products.js             = البيانات اللي الموقع بيقرأها (يتولّد تلقائياً)
  data.json               = الملف الحي اللي الموقع المنشور بيقرأه
  sync_catalog.py         = سكربت مزامنة كتالوج واتساب/الميتا
  مزامنة_الكتالوج.bat     = شغّله بضغطة زر على ويندوز
  config.json             = إعدادات الكتالوج والتوكن
  catalog.json            = نسخة مقروءة من آخر مزامنة
  .github/workflows/      = مزامنة تلقائية كل 6 ساعات على GitHub
  README.txt              = الدليل ده

====================================================
أولاً: النشر المجاني على GitHub Pages (خطوة بخطوة)
====================================================
1) اعمل حساب github.com (مجاني) لو معندكش.

2) اعمل repository جديد:
   - الاسم مثلاً: vayat
   - Public (عشان GitHub Pages يشتغل مجاناً)
   - اضغط Create repository.

3) ارفع كل الملفات اللي في المجلد ده داخل المستودع:
   - اضغط "uploading an existing file"
   - اسحب كل الملفات بما فيها المجلد .github
   - اضغط Commit changes.
   (أو استخدم GitHub Desktop أسهل لو مش عارف ترفع بالمتصفح.)

4) فعّل GitHub Pages:
   Repository → Settings → Pages
   Source: Deploy from a branch
   Branch: main  /  (root)
   اضغط Save.
   بعد دقيقة أو اتنين الموقع هيبقى على:
   https://اسم-حسابك.github.io/vayat/

5) افتح الرابط ده وجرّب — الموقع شغال قدام أي حد في أي جهاز.

====================================================
ثاني: ربط لوحة الأدمن بالموقع المنشور
====================================================
1) اعمل Fine-grained personal access token:
   github.com → Settings → Developer settings
   → Personal access tokens → Fine-grained tokens → Generate new token
   - Token name: vayat-site
   - Repository access: اختر مستودع vayat فقط
   - Permissions → Repository permissions → Contents: Read and write
   - اضغط Generate token وانسخه (هيظهر مرة واحدة بس).

2) افتح admin.html على جهازك (أو على الرابط المنشور بـ /admin.html)
   وادخل كلمة المرور: vayat2026  (غيّرها بعد كده من الإعدادات).

3) من تبويب «الإعدادات» املأ:
   اسم المستودع:   اسم-حسابك/vayat
   الفرع:          main
   توكن GitHub:    التوكن اللي نسخته
   واضغط «اختبار الاتصال» لازم يطلع ✅.

4) من دلوقتي: أي تعديل في المنتجات أو النصوص أو الصور بيتحفظ
   تلقائياً وبيترفع على GitHub، وكل العملاء يشوفوه خلال ثواني.

⚠️ التوكن موجود بس على جهاز الأدمن (في localStorage)، مش موجود
   في ملفات الموقع، فالعميل ما بيشوفهوش أبداً.

====================================================
ثالثاً: مزامنة كتالوج واتساب تلقائياً
====================================================
رابط wa.me/c/... نفسه ما بيحتويش على بيانات، فالموقع بيقرأ من
Meta Graph API الرسمي. الشرط: الكتالوج يكون في Commerce Manager:
  business.facebook.com/commerce/catalogs

1) انسخ Catalog ID واعمل System User Token بصلاحية catalogs_read
   من: Business Settings → Users → System Users → Generate Token.

2) في المستودع على GitHub:
   Settings → Secrets and variables → Actions → New repository secret
   اعمل سرّين:
     CATALOG_ID     = رقم الكتالوج
     CATALOG_TOKEN  = التوكن

3) خلاص. ملف .github/workflows/sync-catalog.yml هيشغّل المزامنة
   كل 6 ساعات تلقائياً، ويرف products.js و data.json والصور للمستودع،
   والموقع يتحدث من غير ما تعمل حاجة.
   تقدر تشغّله يدوياً من تبويب Actions → Run workflow.

لو مش عايز GitHub Actions، شغّل مزامنة_الكتالوج.bat على جهازك
بعد ما تكتب رقم الكتالوج والتوكن في config.json.

====================================================
ترتيب الأولوية
====================================================
  - أحدث تعديل (من الأدمن أو من مزامنة الكتالوج) هو اللي بيظهر.
  - الموقع بيقرأ data.json من GitHub Pages في كل زيارة.
  - العميل دايماً للقراءة فقط، مفيش أي زرار تعديل في صفحته.
